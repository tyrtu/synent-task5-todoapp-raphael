# Todo App

A lightweight todo manager built with vanilla JavaScript. It helps you capture daily tasks quickly, keep track of progress, and filter work by status without needing a backend.

## Features

- Add new tasks with one form.
- Mark tasks as completed or active.
- Delete individual tasks.
- Clear all completed tasks in one action.
- Filter the list by all, active, or completed items.
- View live counters for total, active, and completed tasks.
- Persist todos in `localStorage` so refreshes do not wipe your list.

## Tech Stack

- HTML
- CSS
- Vanilla JavaScript
- Browser `localStorage`

## How It Works

The app keeps all state in the browser. When you add, toggle, or delete a todo, the UI re-renders immediately and saves the updated list back to `localStorage`.

## Run Locally

1. Open `index.html` in your browser, or use a local server such as VS Code Live Server.
2. Start adding tasks.
